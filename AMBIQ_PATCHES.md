Every change preserves the upstream `arm_*` function signatures, instance types, and documented storage contracts except where a row says otherwise; each code change carries a regression under `Testing/Regression/` that passes on the patched source and fails on the unmodified upstream source, and documentation-only rows say so in their Regression cell. Upstream disposition for every row: deferred; nothing has been submitted to Arm.

Evidence platform unless stated: Corstone-300 FVP 11.24.13 (Cortex-M55), Arm GNU 14.3.Rel1, `-O3 -ffast-math`, handwritten MVE enabled, MPU guard immediately after the buffer under test.

## Toolchain

Helium builds of this fork use ATfE 22.1.0 (decision 2026-10-01). Arm GNU Toolchain 15.2.Rel1 is excluded for Helium builds because of the writeback-gather defect above, which affects every MVE complex FFT (`arm_cfft_f32/q31/q15/f16.c`, 16 call sites, the only users of `*_wb` gather and scatter intrinsics in `Source/`). Arm GNU 14.3.Rel1 is correct for those kernels but cannot compile the f16 MVE kernels (`_Float16` ICE), so it is permitted only with `DISABLEFLOAT16`.
